# Project Instructions

For all future website styling and UI work in this project, use the palette and guidance in [spec.md](./spec.md):

- Emerald: `#10B981`
- Cream: `#FFFBF0`
- Soft Gray: `#E5E7EB`

Use these as the site's default design tokens. Apply Emerald as a deliberate accent, Cream for primary surfaces, and Soft Gray for neutral support. Retain suitable dark foreground colors for text contrast, and verify accessibility for text, focus, and interactive states. Follow existing component and responsive-layout conventions.
